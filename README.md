# EduVidGen-AI-Based-Text-to-Video-Educational-System

Tech Stack: Python, Next.js, React, Tailwind CSS, Supabase, PostgreSQL, Mistral-7B, Llama-3.3-70B, ChromaDB, RAG, Playwright, FFmpeg, Edge-TTS
- Designed and developed an end-to-end AI-powered educational video generation system.
- Automated educational script generation using Large Language Models (LLMs).
- Implemented Agentic RAG with ChromaDB for context-aware content retrieval.
- Generated HTML slides, narration audio, and synchronized multimedia into MP4 videos using Playwright and FFmpeg.
- Built a secure full-stack web application with authentication and cloud storage.
